# Requirements

1. **Indicator-Gated Activation**: Active only when the turn indicator is ON.
2. **Warning-Only Authority**: Zero control over throttle, braking, or steering.
3. **Risk Calculation**: Based on Time To Collision (TTC).
4. **Security**: Data validation, watchdog monitoring, no hardcoded secrets, fail-safe.
5. **Quality**: Zero static analysis errors, comprehensive unit and integration tests.
